## Séance 2 — XAML, Layout et Envoi de mail
> **Statut :** En cours

### Théorie (1 h)

- **Langage XAML** — syntaxe, éléments, attributs, balises auto-fermantes.
- **Éléments de Layout** — `Grid`, `StackPanel`, `DockPanel`, `WrapPanel`, `Canvas`.
- **Code-behind C#** — interaction entre la vue XAML et la logique métier, gestion des événements.

### Pratique (3 h)

#### Objectif

Créer un projet **WPF (.NET Framework)** versionné sur **GitHub** et y développer une **application de gestion d'envoi de mail**.

#### Cahier des charges

L'utilisateur encode :

| Champ | Description |
|---|---|
| 📧 Adresse mail (expéditeur) | Adresse Gmail ou Outlook/Hotmail **personnelle** |
| 🔑 Mot de passe | Clé d'application (générée via 2FA) |
| 👤 Destinataire | Adresse mail du destinataire |
| 📝 Objet | Objet du message |
| 💬 Message | Corps du message |

#### Spécifications techniques

- **Type de projet :** Application WPF (.NET Framework).
- **Envoi :** utilisation de l'espace de noms `System.Net.Mail` (`SmtpClient`, `MailMessage`).
- **Gestion d'erreurs :** capture propre des exceptions, feedback utilisateur en cas d'échec d'envoi.
- **Versioning :** dépôt GitHub mis à jour régulièrement.

#### Note importante — Authentification SMTP

> **Les adresses mail étudiantes ne fonctionnent plus.**  
> Il est **obligatoire** d'utiliser une **adresse personnelle** configurée comme suit :

| Fournisseur | Configuration requise |
|---|---|
| **Gmail** | Authentification **2 étapes** activée + **clé d'application** dédiée |
| **Outlook / Hotmail** | Authentification **2 étapes** activée + **clé d'application** dédiée |

Les **paramètres SMTP** correspondants (serveur, port, SSL) doivent être recherchés en ligne pour chaque fournisseur.

#### Liens utiles

- Créer un mot de passe d'application pour Gmail :  
  <https://support.google.com/mail/answer/185833?hl=fr>
- Gérer la vérification en deux étapes (compte Microsoft) :  
  <https://account.live.com/proofs/Manage/>
